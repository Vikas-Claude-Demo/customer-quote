⚠ Ring & CGM Dependency Map — MVP Without Wearable Integrations

If Ring and CGM integrations are excluded from the MVP, the highlighted rows below show parameters that will not have real-time data. These would need manual entry, lab-only fallbacks, or be hidden until integration is added.

NEEDS RING — Requires Ring wearable (HRV, Sleep, Recovery, RHR, Stress, Skin Temp) NEEDS CGM — Requires CGM device (Real-time Glucose, Glucose Variability) NEEDS RING + CGM — Requires both integrations

Impact summary: ~18 parameters need Ring, ~5 parameters need CGM, ~6 parameters need both. Without these integrations, the Home screen loses real-time metrics (HRV, Sleep, Glucose, Recovery, Stress), the Overall Performance Score becomes partial, and AI Coach loses wearable context.

✅ v1 Source Strategy — HealthKit / Health Connect Fallback (No Ring SDK Required)

Every NEEDS RING row below now shows a v1 source note in green. The MVP ships with a single Apple HealthKit + Android Health Connect integration that pulls the same data from whichever smart watch the user already owns — Apple Watch, Wear OS (Pixel/OnePlus), Galaxy Watch, Garmin, Fitbit, Whoop, Oura. CGM data (Dexcom G6/G7, FreeStyle Libre 2/3) also flows through HealthKit / Health Connect, so the NEEDS CGM rows are covered too.

Full coverage via HK/HC: HRV, Sleep stages, RHR, VO2 Max, Glucose, Skin Temp (Watch S8+/Oura/Whoop) Computed in v1: Recovery Score, Stress Level, Readiness (derived from HRV + Sleep + RHR) Still gaps in v1: Blood Pressure (manual / cuff), proprietary brand scores (Body Battery, Whoop Strain)

Impact of this strategy: ~16 of 18 NEEDS RING rows light up on day 1 without owning a Ring. All 5 NEEDS CGM rows light up if the user has a Dexcom or Libre app installed. The Ring SDK becomes an upgrade path (richer night-time SpO2, continuous skin temp), not a v1 blocker.
