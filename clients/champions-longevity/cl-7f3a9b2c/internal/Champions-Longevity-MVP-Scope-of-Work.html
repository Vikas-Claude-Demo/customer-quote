Shared Infrastructure

Foundation services that all 4 MVP modules depend on. Built in Layer 0 before any module work begins.

Authentication & Identity

  • Auth Service — Email + OTP signup, Apple / Google SSO, JWT issuance, refresh token rotation
  • User Service — Profile storage, demographic data, goals, preferences, timezone
  • RBAC — 6 admin roles (Super Admin, Ops, Content, Finance, Support, Clinician)
  • Biometric re-auth — FaceID / TouchID for sensitive actions
  • Audit Log Service — Immutable trail of PII access & admin mutations

Backend Services

  • API Gateway — Rate limiting, request routing, authentication middleware
  • Notification Service — Push notifications (FCM/APNs), email (transactional + marketing), in-app
  • Payment Infrastructure — Payment gateway integration (INR), subscription billing, refund handling
  • File Storage — S3-compatible storage for PDFs, lab results, images
  • Job Scheduler — Cron-based jobs for daily insights, weekly narratives, session reminders
  • Event Bus — Async messaging between services (booking confirmed, results uploaded, etc.)

Admin Console Base

  • Admin shell — Authenticated web app with role-based navigation and layout
  • User search & management — Lookup by email / phone / ID, view profile + devices
  • Dashboard framework — Reusable chart components, KPI cards, data tables
  • Content management — Rich text editor for descriptions, protocol docs, therapy details
  • Support ticket inbox — Tickets tied to user record + history for support agents
